# Hala Kommers Admin

واجهة أدمن React تستخدم نظام التصميم المعتمد في مشروع **hala kommers seller new desi**.

## التصميم
- نفس ملف الستايل المشترك من `/Volumes/Work/تصميم هلا /dashboard-heroui/src/styles.css`.
- IBM Plex Sans Arabic محلي بأوزان 400/500/600، HeroUI 3.2.6، أيقونات Gravity، RTL، ومؤشرات AnimatedNumber المشتركة.
- إضافات الأدمن فقط في `src/admin.css`.
- قائمة الأدمن والإعدادات من صور المستخدم. الوضع الفاتح افتراضي، والداكن اختيار داخل الجلسة.

## حدود المعاينة
لا يوجد اتصال بـ API أو قاعدة بيانات هلا. بناءً على طلب إضافة بيانات تفصيلية، تستخدم التحليلات 480 طلبًا تجريبيًا مترابطًا: 8 بائعين و6 موظفين و12 متجرًا و3 أكونت مانجر، خلال 1–24 أكتوبر 2026، بالدولار. جميع الأسماء والأرقام توضيحية.

تشمل المعاينة فلاتر متقاطعة للفترة والبائع والموظف والمتجر والأكونت مانجر والدولة والحالة وشركة الشحن والمنتج، مع كروت الأداء والتشغيل والماليات، ورسوم يومية وتوزيع الدول، ومقارنات الأشخاص والمتاجر. الجداول تدعم البحث والترتيب وتصدير CSV، وتفاصيل الكيان مع طلباته وتقسيم صفحات الطلبات. الإيراد للتسليم فقط؛ هامش المساهمة يخصم المنتجات والشحن فقط.

التعديلات على الطلبات والبائعين والمهام محفوظة محليًا خلال جلسة المتصفح، وتتشاركها صفحات الإدارة. بقية الوحدات التي لم تتوفر لها بيانات تبقى حالات معاينة واضحة.

## التشغيل
`pnpm install`

`pnpm dev --host 127.0.0.1 --port 5174`

`pnpm build`

## المراجعة
`node --test tests/admin-analytics.test.mjs` يفحص ترابط البيانات وتقاطع الفلاتر واتساق الحسابات.

`design-qa.md` يسجل فحص التصميم والتفاعلات والموبايل والوضع الداكن.

## مراحل الطلبات والشحن
ملخص الشحن يظهر مباشرةً بعد الطلبات. تحليل المراحل يعرض 13 حالة للطلبات و8 للشحن، من الجديد والتأكيد والتجهيز إلى الالتقاط والنقل والخروج للتسليم وتعذر التسليم والتسليم والإرجاع. الضغط على الحالة يطبق فلترها على اللوحة. جدول شركات الشحن يوزع شحنات كل شركة على المراحل مع نسبة الاستلام؛ جاري الإرجاع منفصل عن المرتجع النهائي. التحليل لتوزيع الحالات الحالية، وليس سجل انتقالات تاريخيًا.

## إدارة البائعين والمتابعات

ملفات البائعين تشمل التحليلات، الفلاتر، الإجراءات الجماعية وسجل التواصل. مهام المتابعة تظهر بلوحة Kanban بثلاث مراحل: للمتابعة، قيد التنفيذ، مكتملة، مع عداد للمهام المفتوحة في القائمة الجانبية. تغيير الحالات متاح بالسحب أو من قائمة الحالة.
